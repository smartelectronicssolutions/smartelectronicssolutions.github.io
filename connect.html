Other option: RustDesk

If your technician asks for RustDesk, or the download above doesn't work, use this free remote support tool instead.

  1. Download RustDesk for your computer using a button below.
  2. Open the downloaded file. On Windows you can just run it - no install needed.
  3. Read your technician the ID and the one-time password shown on the left of the RustDesk window.
  4. When the technician connects, click Accept. On a Mac, allow Screen Recording and Accessibility if macOS asks.
  5. When you're done, close RustDesk to end the session.
