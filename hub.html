How this hub works show

Two hubs, one picture. This hub runs on se. The pi-hub runs on the Pi 4 (192.168.50.149), a second machine, so it still works when se is down. Anything about the network comes from the pi-hub, read live, so both pages show the same numbers. This hub adds the console, routines, to-dos, work, notes and money.

Cards. Hold a card's title and drag it onto another card to swap them. Triple-click a title to switch between full width and half. The layout is saved to your account, so it's the same on every device.

Links: your Online Links bookmarks, with a filter and category. Quick Commands: your saved commands. MC Server: status from anywhere; start/stop only on the house wifi.

To-Dos / Upcoming Work / Recent Topics / Quick Notes: your lists from kh, onlinejob, the journal and onlinenotes. To-Dos scrolls.

Services: up/down for cloud sites, LAN apps, containers, House Watch (the pi-hub's 15-second watchdog) and the AI bridges with Start/Stop.

Network Health: the pi-hub's own numbers. Pi temperature, uptime, mode and whether pibot is running. Internet and se up % with latency for the last 24 h. Outage episodes, gaps, and the last alerts (the same lines that go to Telegram).

Network: every named device. With the house wifi, each row gets a live dot and uptime % from the pi-hub, plus any device the Pi knows that this list doesn't. Off the LAN it's the saved list only.

Internet Data: down/up from the EdgeSwitch's uplink port. The pi-hub keeps its own count of the same port, so the two can be a few MB apart.

Claude Usage / Server Drives / Client Info / Microsoft / Credentials: plan usage, se disks, this browser, the OneDrive token and saved logins.

Goings-On: mail waiting for Droplet plus open JE Auto Care tickets. "Quiet" = nothing. Tickets / Inventory: the repair shop. Site Statistics: who visited the sites.

Only on the pi-hub (LAN): Network Mode (router failover), Wi-Fi, Tor, cameras/NVR, network tools, speed test, the 7-day network log, Power. LAN only: everything that reads the Pi needs the house wifi or Tailscale.
